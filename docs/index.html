Your music follows the round.

VibePause pauses your music when a VALORANT round starts, then plays it again when you die, buy, or head back to the lobby. It runs quietly in your tray.

How it works

No overlay, no hooks into the game. VibePause only reads a file and presses play or pause for you.

It reads the game log

VALORANT writes ShooterGame.log on your own PC. VibePause follows that file to spot round starts and match changes, and uses Windows' built-in OCR to detect when you're eliminated.

It matches the event

Each event has the action you chose: Play, Pause, or None, or a volume level in Volume mode. A delay setting lets you shift when it fires.

It controls your media

It uses Windows media controls, so Spotify, YouTube Music, Apple Music and browser players all work. Call apps like Discord are left alone.

Installing with Windows SmartScreen

VibePause is a new project and the installer is not code-signed yet. We plan to apply for free code signing from the SignPath Foundation once the project has built up a track record, so Windows may show a warning for now. Only continue if you downloaded the installer from this page or the official Releases page.

Run the installer

Open VibePause_Setup.exe. If your browser says it isn't commonly downloaded, open the download's menu (…), choose Keep, then Keep anyway. The wording differs between browsers.

Click More info

If Windows shows "Windows protected your PC", click More info. The publisher appears as Unknown because the installer is not signed yet.

Click Run anyway

The installer then opens. It installs for your user account, so no administrator rights are needed.

Want to check the file first? In PowerShell, run Get-FileHash .\VibePause_Setup.exe and compare it with the VibePause_Setup.exe.sha256 file on the release page.

It stays out of your game.

VibePause is a separate app that talks to Windows, not to VALORANT.

  • No injecting into VALORANT
  • No reading game memory
  • No changing game files
  • No gameplay input
  • No in-game overlay
  • No Riot account details
