# VibePause

Get VibePause_Setup.exe without installing anything locally:
1. Push this folder to a GitHub repo (private is fine).
2. Open the Actions tab, run "Build VibePause" (it also runs on every push).
3. Download the "VibePause_Setup" artifact, unzip it, run VibePause_Setup.exe.

Or on a Windows PC with Python 3.10+ and Inno Setup: run BUILD.bat.
