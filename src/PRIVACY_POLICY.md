# Privacy Policy for VibePause

Last updated: October 6, 2026

tanveer-exe ("us", "we", or "our") operates the VibePause application (the "Service").

This page explains what VibePause does and does not do with your data.

## Summary

VibePause runs on your computer. It does not collect, store or sell personal data, and it has no account, tracking, analytics, advertising or cookies.

## Data VibePause Does Not Collect

- Your name, email address, phone number or address
- Your Riot Games account details, passwords or authentication tokens
- Game memory, screenshots or gameplay input
- Usage statistics, analytics or crash reports
- Any information about the music or media you play

## Data Stored On Your Computer

VibePause saves your settings in a file named settings.json in the Documents\VibePause folder. This file contains your chosen actions for each game event, the event delay, your startup and tray preferences, update check preference, and which version of the legal terms you accepted.

This file stays on your computer. It is never uploaded. Uninstalling VibePause keeps this file so your settings survive a reinstall. You can delete the folder yourself at any time.

## What VibePause Reads

- The VALORANT game log file on your computer (ShooterGame.log), read locally to detect game events such as a round starting. Nothing from this file is sent anywhere.
- Windows media sessions, which VibePause uses to play or pause your music. VibePause does not read the titles, artists or content of what is playing.

## Network Use

VibePause connects to the internet only to check for and download updates from GitHub (github.com and api.github.com). These requests carry the app name and version in the request header, and GitHub will see your IP address as with any web request. No other information is sent.

If you turn off automatic update checks, VibePause only contacts GitHub when you click Check for updates.

GitHub's handling of that connection is covered by the GitHub Privacy Statement.

## Sharing Of Data

We do not share your data with anyone because we do not receive it.

## Security

Because your settings never leave your computer, their security depends on your own device and account. The update installer is downloaded from the official GitHub release over HTTPS.

## Children's Privacy

VibePause does not collect personal data from anyone, including children.

## Changes To This Privacy Policy

We may update this Privacy Policy from time to time. Changes are posted with the app and on the project's GitHub page, and the date at the top is updated. When the policy changes, VibePause asks you to review and accept it again.

## Contact Us

If you have any questions about this Privacy Policy, please open an issue at https://github.com/Tanveer-exe/VibePause/issues.
